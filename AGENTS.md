# Contributor instructions

This is the public monitoring module, not a private deployment. Preserve local
work and upstream licenses. Never copy private site files, keys, archives,
passwords, generated QR codes, databases, logs or screenshots from a real host.
Use only synthetic fixtures. Do not contact a server, change a host, install a
system service or send power/WOL requests to validate this repository.
Keep commands allowlisted, sudo interactive, SSH keys verified and TLS validation
enabled. Actions stay disabled by default. Unknown activity must block shutdown.
Run Python tests, chart tests and language syntax checks. Do not equate mocks,
an SSO lab or a configured workflow with real-device recovery or production SSO.
